## Install

### Windows

### [&#11015; DOWNLOAD — BSMT-DSP-Setup-1.2.0.exe](https://github.com/Dalailalama/bsmt-dsp-releases/releases/download/v1.2.0/BSMT-DSP-Setup-1.2.0.exe)

*(Windows 64-bit installer. That link is all you need — the "Source code"
zips GitHub adds under Releases are automatic and contain nothing but this
page.)*

1. Download the installer above.
2. **Close your DAW**, then run it. Windows SmartScreen may warn on new
   releases (unsigned indie build) — click **More info → Run anyway**.
3. Pick your plugins and the VST3 folder (default
   `C:\Program Files\Common Files\VST3`). Standalone apps are optional and
   off by default — tick STANDALONE APPS if you want them.
4. Rescan plugins in your DAW. Done.

### macOS (beta)

### [&#11015; DOWNLOAD — BSMT-DSP-mac-1.2.0.zip](https://github.com/Dalailalama/bsmt-dsp-releases/releases/download/v1.2.0/BSMT-DSP-mac-1.2.0.zip)

VST3, Apple Silicon + Intel. Unzip, double-click `INSTALL.command`, then
rescan plugins in your DAW. If macOS blocks the script the first time:
right-click → Open, or System Settings → Privacy & Security → Open Anyway.
The Mac build is a beta (unsigned, and not yet tested by us in a Mac DAW) —
tell us how it runs.

## Updating

From v1.2.0 on, every plugin shows a small **UPDATE AVAILABLE** badge when a
newer version is out (it looks once a day; nothing is downloaded or installed
by the plugin — a click opens this page). To update: close your DAW and run
the newer installer. It detects your version and updates in place. Projects
and presets are untouched.

Don't want the check? Add the line `update.check=0` to
`%APPDATA%\DRDAWGOG\BSMT.DSP\settings.ini` (macOS:
`~/Library/Application Support/DRDAWGOG/BSMT.DSP/settings.ini`).

## What's new in v1.2.0

All 27 plugins were revised from the inside: safer with every buffer size
